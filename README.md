# midi2jianpu

> 直接将 MIDI 文件转换为排版美观、可打印的中文简谱（数字谱）。

中文说明 | [English](README_EN.md)

## 这是什么

`midi2jianpu` 是一个面向中文音乐人的开源工具：你手里的 `.mid` 文件——FL Studio 导出、电子琴/合成器录制、扒谱工程——拖进来，就能得到一份排版干净、可以直接打印或在手机上看的**中文简谱（数字谱）**。

### 与现有方案的区别

- 大多数简谱工具从 **MusicXML / 五线谱**倒推，而音乐人手里最多的文件其实是 **MIDI**；
- 现有脚本多是一次性转换器，输出格式杂乱、不能编辑、不能排版；
- 本项目目标是「拖入 MIDI → 干净简谱」一步到位，并保留可编辑性。

## 功能规划

- [x] 解析标准 MIDI 文件（多轨、多通道、可变速度）
- [ ] 自动识别调性，换算成简谱首调唱名（1 = C 等）
- [ ] 识别拍号、小节线、时值（含附点、连音、休止符）
- [ ] 排版为标准简谱：八度点、时值线、延音线、强弱记号
- [ ] 导出 PNG / PDF 可打印谱面
- [ ] 桌面端（C++，Windows）与网页端（WASM）双形态

## 技术选型

- 核心解析引擎：**C++**（追求速度与可嵌入性，便于编译成 WASM）
- 桌面端：C++ / Qt 或原生 Win32
- 网页端：同一核心编译为 WASM，浏览器直接跑

## 路线图

近期优先：MIDI 解析 → 调性识别 → 基础简谱文本输出 → 排版渲染。

## 为什么开源

中文简谱是中国特有的记谱体系，国外打谱软件（MuseScore、Finale）对它支持很差，国内又一直缺少一个干净的、可二次开发的基础库。这个项目想把「MIDI → 简谱」这层地基打好，让后来的人不用重复造轮子。
