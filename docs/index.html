歌词（可选）：粘贴 LRC / JSON 文本，或选择 .lrc / .json 文件
歌词会按时间戳对齐到音符，只显示在旋律轨上；一字多音会画连音线，下载 MusicXML 也带词。文件自带歌词时无需再找 LRC（提示栏会点明词在第几轨、有没有别的轨被忽略），粘贴的 LRC 优先级更高。中途变拍号、弱起、变速、转调会自动识别：前三者按段划分小节线，转调则按段重算唱名。中国民歌/古风曲若只用五声音阶，自动识别会按宫音定 1（如 G 徵调式记 1=C 而不是 1=G），判错时可在「宫音」下拉里手动指定（与命令行 `--gong` 同源），关掉上方复选框可回到大小调判定。LRC 的 [mm:ss.xx] 会按曲中变速分段换算成谱面位置，也支持 [offset:±毫秒] 与一行多个时间戳；JSON 歌词（[{"start_beat":N,"text":"…"}]）同样认，格式按内容自动判定，和命令行一个口径；歌词文件也可以直接拖进页面，提示栏会回显「按 LRC / JSON 解析 N 字」，一个字都没认出来时同样直说。文件里的力度（CC11）、note-on 力度、弯音与段落标记会自动转成谱面上的 mf/渐强/断音/滑音/段落名，三个导出通道同步；不想要这些记号可关掉「力度与演奏法」。
